# 告警提示流

`NewAlertNotification` 组件配合 `App.vue` 中的轮询机制，实现新告警的**右上角浮动通知**。

---

## 整体流程

```text
[ 用户登录成功 ]
        │
        ▼
[ 启动轮询 startAlertCheck() ]
        │
        ├── 延迟 3 秒后首次检查
        └── 每 20 秒轮询一次 checkNewAlerts()
                  │
                  ▼
        ┌─── 是否已登录？ ──否──► 跳过
        │
        ▼
        ┌─── 是否在告警页面？ ──是──► 跳过（已在看告警）
        │
        ▼
        ┌─── 是否在免打扰期？ ──是──► 跳过
        │       ├── snooze 未到期（30min/1h/今天）
        │       └── ignore 30秒内
        │
        ▼
        ┌─── 是否已弹窗？ ──是──► 跳过（不重复弹）
        │
        ▼
        [ 调用 getLatestWarnInfo() 拉取最新告警 ]
        │
        ▼
        ┌─── 是否有新数据？ ──否──► 跳过
        │
        ▼
        ┌─── lastConfirmed 是否存在？ ──否──► 初始化时间戳，不弹历史告警
        │                                          （首次登录）
        ▼
        [ 过滤 warnTimestamp > lastConfirmed 的新告警 ]
        │
        ▼
        ┌─── 有新告警？ ──否──► 跳过
        │
        ▼
        [ 弹出右上角通知: alertNotificationCount / latestAlertInfo ]
```

---

## 核心机制

### 1. 轮询启动 (`startAlertCheck`)

- **首次检查**：路由就绪后延迟 **3 秒**（确保登录流程完成）
- **轮询间隔**：每 **20 秒**一次
- **停止条件**：用户登出时调用 `stopAlertCheck()`

### 2. 免打扰系统 (`isInSnoozePeriod`)

三种暂停策略，均存储在 `localStorage`：

| 策略            | key                  | 有效期                  |
| --------------- | -------------------- | ----------------------- |
| **忽略**（点×） | `alert_ignore_until` | 30 秒（防刷新后重复弹） |
| **30 分钟**     | `alert_snooze_until` | 当前时间 + 30min        |
| **1 小时**      | `alert_snooze_until` | 当前时间 + 60min        |
| **今天**        | `alert_snooze_until` | 当天 23:59:59.999       |

### 3. 新告警过滤

基于时间戳对比：

```
lastConfirmed = localStorage.getItem('alert_last_check_time')
```

- **首次登录**：`lastConfirmed` 不存在 → 初始化为当前 `Date.now()`，不弹旧告警
- **后续轮询**：只弹 `warnTimestamp > lastConfirmed` 的告警
- **确认时机**：用户点击"查看告警"或"忽略"时更新 `alert_last_check_time`

### 4. 路由守卫联动

- 如果用户自行导航到 `/alarm-monitoring`（告警监视处理），自动关闭通知并确认
- 已在告警页面时不再弹出新通知

## 通知组件 (`NewAlertNotification.vue`)

右上角浮动卡片，结构如下：

```
┌──────────────────────────────────┐
│  [🔔] 新告警通知              [×] │
├──────────────────────────────────┤
│                                  │
│          42                       │
│        条新告警                    │
│                                  │
│  [⚠️] 系统检测到设备CPU过载...     │
│                                  │
│  [查看告警]  [忽略]  [暂不提醒 ▾]  │
│                         ├ 30分钟  │
│                         ├ 1小时   │
│                         └ 今天    │
└──────────────────────────────────┘
```

### 操作说明

| 操作         | 行为                                                |
| ------------ | --------------------------------------------------- |
| **查看告警** | 跳转 `/gj-monitoring`（告警信息处理），关闭通知     |
| **忽略**     | 记录 `alert_ignore_until`，30 秒内不再弹出          |
| **暂不提醒** | 根据选择的时间段记录 `alert_snooze_until`，期间不弹 |

## 数据流与生命周期图

```text
App.vue (mounted)
    │
    ├── startAlertCheck()
    │       ├── setTimeout(3s) → checkNewAlerts()
    │       └── setInterval(20s) → checkNewAlerts()
    │
    ├── checkNewAlerts()
    │       ├── isInSnoozePeriod()  ← localStorage
    │       ├── getLatestWarnInfo() ← API
    │       ├── getLastConfirmedTime() ← localStorage
    │       ├── 过滤新告警
    │       └── 弹窗: showAlertNotification = true
    │
    ├── NewAlertNotification (props)
    │       ├── visible / alertCount / latestAlert
    │       ├── @close → showAlertNotification = false
    │       ├── 查看告警 → router.push('/gj-monitoring')
    │       ├── 忽略 → localStorage.setItem('alert_ignore_until')
    │       └── 暂不提醒 → localStorage.setItem('alert_snooze_until')
    │
    └── router.afterEach
            └── /alarm-monitoring → 自动确认并关闭
```
